# Imagens da capa e galeria

Esta área reúne as imagens padrão usadas pelo template.

## Capa

Coloque a foto autorizada do cliente em:

`recursos/imagens/capa/`

Depois informe **somente o nome do arquivo** em `javascript/configuracao.js`:

`heroImage: "hero.jpg"`

O template já inclui uma capa padrão local em `hero.svg`.

## Galeria

Coloque as fotos autorizadas do cliente em:

`recursos/imagens/galeria/`

Na configuração, informe o caminho local de cada imagem:

`src: "recursos/imagens/galeria/foto-01.jpg"`

O template inclui seis imagens SVG locais de demonstração. Substitua os arquivos ou altere os valores de `CONFIG.galeria` para usar as fotos do cliente.

**Importante:** a galeria não depende de Pexels, Unsplash ou qualquer outro serviço externo.
